## 私有信息边界

本机已有的 env 文件随代码完整保留。可读取的线上普通变量导出到 `.private/`。
Cloudflare 加密 Secret（例如 jwt_secret、D1_REST_API_TOKEN）不能从平台读取原值，
导出的只是名称；如本机没有原值，不能声称已完整备份，恢复时需找原密钥或谨慎轮换。
原始对话可能含凭证，仅存于受保护归档，不作为普通项目文档发布。

旧任务目录通过符号链接指向新根目录，兼容原任务路径；后续开发直接使用新目录。
